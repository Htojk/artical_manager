# Spec Delta

## Purpose

让各生成阶段可配置并加载可复用的技能（尤其是写作风格技能），通过统一清单、校验与绑定机制把技能内容注入对应 Agent，并支持启用、停用与编辑。

## ADDED Requirements

### Requirement: 技能发现与清单
系统 SHALL 从配置的技能目录中发现技能，每个技能 MUST 提供包含名称、描述、版本、适用阶段与入口文件的清单，并支持附带参考文件。

#### Scenario: 启动时发现技能
- **WHEN** 系统启动且技能目录中存在「科技评论文风」技能
- **THEN** 该技能出现在技能列表中，展示名称、描述、版本与适用阶段

#### Scenario: 新增技能目录
- **WHEN** 用户把一个符合清单规范的技能目录放入技能根目录
- **THEN** 刷新后系统识别该技能，无需修改代码

### Requirement: 技能校验与错误隔离
系统 SHALL 在加载时校验技能清单与入口文件；校验失败的技能 MUST 被标记为无效并给出原因，不得导致系统启动失败或影响其他技能。

#### Scenario: 清单缺少必填字段
- **WHEN** 某技能清单缺少名称字段
- **THEN** 该技能被标记为无效并显示缺失字段，其他技能正常工作

#### Scenario: 入口文件不存在
- **WHEN** 技能声明的入口文件不存在
- **THEN** 系统标记该技能不可用，并在引用该技能时记录降级原因

### Requirement: 按阶段绑定技能
系统 SHALL 支持为写作、审核等阶段分别绑定一个或多个技能，并保证同阶段多技能按配置顺序组合注入。

#### Scenario: 写作阶段绑定风格技能
- **WHEN** 用户将「科技评论文风」绑定到写作阶段
- **THEN** 写作 Agent 的每次生成都加载该技能内容

#### Scenario: 多技能组合
- **WHEN** 写作阶段同时绑定了风格技能与事实核查技能
- **THEN** 两个技能的内容按绑定顺序共同注入写作上下文

### Requirement: 技能内容注入
运行时系统 SHALL 将已启用技能的内容注入对应 Agent 的系统提示或上下文，且 MUST NOT 将未启用或已失效技能注入。

#### Scenario: 停用技能不再生效
- **WHEN** 用户停用某个已绑定技能
- **THEN** 后续生成不再包含该技能内容

### Requirement: 技能管理与预览
系统 SHALL 提供技能的查看、编辑、启用/停用与效果预览能力，修改后的技能在下次生成时生效。

#### Scenario: 编辑技能内容
- **WHEN** 用户修改技能入口文件的风格规则并保存
- **THEN** 下次写作使用修改后的规则，并记录技能版本变化

### Requirement: 内置写作风格示例技能
系统 SHALL 提供一个可用的内置写作风格技能示例，作为用户自定义风格技能的模板。

#### Scenario: 首次启动可用
- **WHEN** 用户首次启动系统
- **THEN** 技能列表中存在一个内置写作风格技能，且可绑定到写作阶段直接使用
