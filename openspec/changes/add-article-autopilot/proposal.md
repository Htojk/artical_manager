# Proposal

## Why

持续产出并分发多平台文章需要反复进行选题、检索、写作、审核、排版、发布和复盘，流程割裂、质量不稳定且成本不可见。本变更构建一个自动写稿与发布 Agent：把文章生产编排为可观测、可回退的 LangGraph 工作流，统一管理多平台适配与发布数据，并基于用户修改意见和文章表现持续优化写法与模型成本。

## What Changes

- 新增前后端分离的 Web 控制台：文章列表、创作工作台、运维分析看板、技能与模型配置。
- 新增文章生成工作流（LangGraph 编排）：选题 → 资料搜索 → 大纲生成 → 写作 → 审核 → 分平台排版 → 发布，支持断点续跑与人工确认。
- 新增审核回退策略：审核节点给出结论与回退目标，可回退到资料搜索、大纲生成或写作阶段，并限制最大返工轮次以避免死循环。
- 新增选题能力：支持手动输入主题，以及 Agent 结合热点自动推荐 5 个候选选题供用户选择。
- 新增平台适配器体系：统一的平台适配器接口，按平台分包（微信公众号、知乎、掘金、CSDN），每个平台目录内实现认证、排版转换、发布与指标抓取；由注册表动态加载。
- 新增可配置技能系统：从技能目录发现、校验并加载技能（写作风格技能优先），按 Agent/阶段绑定并在调用时注入。
- 新增运维分析能力：记录发布状态与每次发布结果，定期抓取或手动回填阅读量、收益，并按文章/阶段/模型统计 Token 用量与成本。
- 新增自进化能力：基于用户修改意见、审核结论与文章表现生成改进建议（写作规则/技能更新/提示词调整/模型降本），经用户确认后生效。
- 新增 SQLite 持久化：文章、工作流运行、阶段产物、发布记录、指标快照、Token 成本台账、技能与模型价格配置。
- 新增 Windows 本地一键启动脚本（安装依赖、初始化数据库、启动前后端）；Docker 部署本轮不实现。
- 前端文章详情页左侧固定竖向流程条展示 7 个节点，节点可点击查看该阶段内容与状态。

**明确不在本轮范围**：Docker 镜像与编排；自动注册平台账号；绕过平台官方接口的自动化（如模拟登录、爬取后台数据）；多用户权限体系。

## Capabilities

### New Capabilities

- `article-generation/workflow`: 文章生成 LangGraph 工作流的节点编排、状态流转、断点续跑、人工确认与审核回退路由。
- `article-generation/topic-selection`: 手动主题录入与热点驱动的 5 个候选选题推荐、选择与落库。
- `article-generation/research`: 资料搜索、来源抓取、引用整理与可信度标注。
- `article-generation/outline`: 基于选题与资料生成结构化大纲及修订。
- `article-generation/writing`: 结合大纲、资料与写作风格技能生成与修订正文。
- `article-generation/review`: 多维质量审核、结论产出与回退目标判定。
- `article-generation/formatting`: 通过平台适配器生成各平台排版产物与预览。
- `article-generation/publishing`: 人工确认后调用平台适配器发布、记录结果并支持重试/幂等。
- `skill-system`: 技能发现、校验、配置、按阶段绑定与运行时加载。
- `analytics/publication-metrics`: 发布状态追踪、阅读量与收益采集/回填、Token 用量与成本核算。
- `self-evolution/writing-improvement`: 基于用户修改与文章表现的写作改进建议，以及按成本与质量的模型选择优化。
- `web-console`: 前后端分离的 Web 控制台与文章流程可视化交互。

### Modified Capabilities

无（项目为全新代码库，尚无既有 spec）。

## Impact

- **新增代码**：`backend/`（FastAPI、LangGraph、deepagents、SQLite）、`frontend/`（React + TypeScript + Vite）、`skills/`（可加载技能）、启动脚本与配置样例。
- **数据模型**：文章、工作流运行与阶段产物、发布记录、平台指标快照、LLM 调用台账、模型价格、技能绑定、自进化建议、平台凭据配置。
- **外部依赖**：OpenAI 兼容 LLM 接口；微信公众号 / 知乎 / 掘金 / CSDN 的开放能力（不可用时降级为导出与手动回填）；可选的搜索/RSS 数据源。
- **运行环境**：Windows 本地一键启动；SQLite 单文件数据库；Docker 延后。
- **兼容性**：全新项目，无破坏性变更。
