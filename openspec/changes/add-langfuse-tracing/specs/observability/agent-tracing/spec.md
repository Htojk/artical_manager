# Spec Delta

## Purpose

为文章生成工作流提供端到端链路追踪，记录每次运行、阶段、模型调用与外部请求的输入输出、耗时和状态，支持按文章与运行回放排查 agent 问题，同时保证默认关闭、失败降级、敏感信息不外泄、数据留在内网。

## ADDED Requirements

### Requirement: 追踪默认关闭且可显式开启

系统 SHALL 默认不开启链路追踪；仅当显式启用并配置追踪后端地址与凭据时才上报。未启用、依赖缺失或后端不可达 MUST NOT 改变工作流结果或阻塞运行，并 MUST 在本地日志留下可诊断的告警。

#### Scenario: 默认关闭

- **WHEN** 启动时未配置启用参数
- **THEN** 系统不初始化追踪客户端、不产生任何上报，现有测试与运行行为保持不变

#### Scenario: 配置不完整

- **WHEN** 已启用但缺少后端地址、公钥或私钥
- **THEN** 系统按未启用处理，并在启动日志中记录缺少的配置项

#### Scenario: 后端不可达

- **WHEN** 已启用但追踪后端网络不可达或返回错误
- **THEN** 文章生成继续完成，不向调用方抛错，仅在本地日志记录告警

### Requirement: 追踪数据写入自托管后端

系统 SHALL 仅将追踪数据写入显式配置的自托管后端地址，默认不向任何外部 SaaS 发送提示词、生成内容或运行数据。

#### Scenario: 内网部署

- **WHEN** 配置指向内网自托管地址
- **THEN** 所有追踪数据只写入该地址，系统不存在默认的公网上报目标

### Requirement: 运行与阶段的层级追踪

系统 SHALL 为每次工作流运行创建根追踪，并为每个执行阶段创建子 span。每个 span MUST 关联文章标识、运行标识、阶段名称与尝试次数，使一次运行的阶段顺序、状态、耗时与错误可以从追踪视图完整还原。

#### Scenario: 完整运行

- **WHEN** 一次运行依次执行选题、研究、大纲、写作、标题、审核、排版与发布
- **THEN** 追踪视图中呈现同一根下的阶段序列，其顺序、状态与耗时和实际执行一致

#### Scenario: 失败与回退

- **WHEN** 某阶段失败或触发回退重做
- **THEN** 失败阶段标记错误，重试与回退产生可区分的新尝试 span，原始尝试仍保留

#### Scenario: 暂停后恢复

- **WHEN** 运行在人工暂停点中断后恢复
- **THEN** 恢复后的阶段仍归入同一运行标识的追踪，不产生无法关联的孤立记录

### Requirement: 模型调用的完整输入输出

系统 SHALL 记录每次模型调用的模型名、输入消息、输出内容、token 用量、耗时与状态。结构化输出失败后的回退调用与修复调用 MUST 分别可见；agent 发起的工具调用 MUST 与其父模型调用形成父子关系。

#### Scenario: 结构化调用

- **WHEN** 阶段调用模型并返回合法结构化结果
- **THEN** 追踪中可见系统消息、用户消息、最终输出、token 用量与耗时

#### Scenario: 回退与修复

- **WHEN** 结构化输出校验失败并回退到 JSON 模式或再次发起修复调用
- **THEN** 每次尝试分别记录，且能看出失败原因与最终采用的结果

#### Scenario: agent 工具循环

- **WHEN** 深度研究 agent 执行搜索、抓取与保存来源
- **THEN** 每次工具调用作为对应模型调用的子 span，记录入参与结果摘要

### Requirement: 外部 IO 的可观测性

系统 SHALL 为热点源抓取、正文抓取、搜索请求与平台发布建立独立 span，记录目标（地址、查询或平台）、耗时、结果状态与截断后的摘要；失败时 MUST 记录错误类型与可用的状态码。

#### Scenario: 抓取与搜索

- **WHEN** 抓取 RSS/HTML 列表、文章正文或调用搜索接口
- **THEN** 追踪中可见目标地址、耗时与结果摘要，超长内容按配置上限截断

#### Scenario: 平台发布

- **WHEN** 向任一平台发布或更新文章
- **THEN** 追踪中可见平台、文章标识与结果状态；失败时可见错误信息

### Requirement: 敏感信息不进入追踪

系统 MUST NOT 将平台凭据、API Key、Cookie、密钥或完整请求头写入追踪数据；对可能包含敏感信息的字段 MUST 采用白名单或脱敏后记录。

#### Scenario: 平台凭据

- **WHEN** 平台发布使用加密凭据
- **THEN** 追踪中只出现平台与结果状态，不出现凭据明文或密文

#### Scenario: 模型配置

- **WHEN** 记录模型调用
- **THEN** 追踪中不包含 API Key、Authorization 头或环境变量原文
